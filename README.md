# Nidhi Singh - Portfolio Website

A modern, responsive portfolio website showcasing my projects, skills, and achievements.

## 🚀 Features

- **Modern UI/UX**: Clean, elegant design with smooth animations
- **Fully Responsive**: Works seamlessly on all devices (mobile, tablet, desktop)
- **Interactive Elements**: Smooth scrolling, hover effects, and animations
- **Hackathon Achievement**: Dedicated section highlighting HACK-A-BOT 2.0 win
- **Project Showcase**: Featured projects with live demos and GitHub links

## 📁 Project Structure

```
portfolio/
├── index.html          # Main HTML file
├── styles.css          # All styling and animations
├── script.js           # JavaScript for interactivity
├── hackathon-image.jpeg # Your hackathon achievement image (to be added)
└── README.md          # This file
```

## 🖼️ Adding Your Hackathon Image

1. Save your hackathon photo (the one with you holding the trophy and certificate) in the root directory
2. Name it `hackathon-image.jpeg` (the HTML already references this filename)
3. Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`

If your image has a different name or format, update the `src` attribute in the `<img>` tag in `index.html`:

```html
<img src="your-image-name.jpeg" alt="HACK-A-BOT 2.0 Champion - Nidhi Singh holding trophy and certificate" class="achievement-image">
```

## 🎨 Customization

### Colors
Edit the CSS variables in `styles.css` to change the color scheme:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --accent-color: #ec4899;
    /* ... more variables */
}
```

### Content
All content is in `index.html`. Simply edit the text, links, and information as needed.
